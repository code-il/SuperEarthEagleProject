Processing
1 · Quality cut

Drop unreliable parallaxes

Stars with G > 19 and RUWE > 1.4 are removed unless SIMBAD knows them: 46,058 removed. These faint, poorly fitted sources gave spurious white dwarfs.

2 · Place

Distance and luminosity

  • d = 1/ϖ → heliocentric Galactic x, y, z in parsecs
  • MG = G + 5 log₁₀(ϖ / 100 mas)
  • No dust-extinction correction
3 · Classify

Catalogue first, then a model

  • SIMBAD type when there is one (77,847)
  • Otherwise k-nearest neighbours (k = 15) on [MG, BP−RP, BP−G, G−RP]: 481,372 predicted
  • 89.7 % correct on a held-out 20 % (13,894 stars)
  • G > 19: [MG, G−RP] only, always low confidence
  • 13,626 without colours stay unclassified
4 · Merge

Add what Gaia misses

  • 4,332 SIMBAD-only objects, e.g. cold brown dwarfs such as WISE 0855
  • Planets attached to their hosts
  • A SPHEREx class replaces the map class only if that class was predicted or missing, or the spectrum shows molecular bands
  • Display name: the common name from SIMBAD's aliases

Cutouts

IRSA cutout service, per exposure

  • IMAGE in MJy/sr, VARIANCE, FLAGS (bit names read from the file's own header)
  • ZODI zodiacal-light model
  • Celestial WCS with SIP distortion; per-pixel wavelength and bandwidth
  • PSF FWHM
Catalogues

Reference catalogues

  • Gaia DR3 and CatWISE2020 cone searches: overlays, registration, cross-match
  • SIMBAD for names, SkyBoT for known asteroids at the frame time
Processing
1 · Clean

Invalid pixels and background

  • NaN values and variance ≤ 0 marked invalid
  • Flags masked by profile (default standard: detector defects, saturation, nonlinearity, persistence, outliers)
  • Background: ZODI model plus a constant median (default), a smooth 2-D mesh, ZODI only, or none
image_processing/prepare.py
2 · Align

One north-up grid

  • TAN grid centred on the target at 6.15″/px, using each file's own WCS
  • Bilinear image; variance Σw²σ² with the same weights
  • Flags: OR of all four contributing pixels
  • Noise-correlation factor per frame (≈ 2.2) for sums and fits
image_processing/align.py
3 · Combine & compare

Stacks, differences, ratios

  • Stacks only frames within one wavelength channel; mixed groups are split
  • A − B after Gaussian PSF and background matching, with significance (A − B)/σ
  • A / B only where B > 0 with S/N ≥ 5; σR² = σA²/B² + A²σB²/B⁴
image_processing/combine.py, pipeline.py
4 · Analyse

Sources, motion, light, spectra

  • Matched-filter detection; visit stacks registered to Gaia (median offset, RMS, max)
  • Motion fit; forced PSF photometry for light curves
  • Spectra binned on the 102 SPHEREx channels
  • Cross-match, then a class: stationary, high proper motion, variable, transient or solar-system candidate

LIMITS

What the pipeline does not do yet

PSF matching is Gaussian

SPHEREx's ePSFs vary across the detector. Matching uses a Gaussian approximation of the FWHM, so bright stars can leave residuals in differences.

Photometry is not The Tractor

Fluxes come from a PSF fit with a local background. IRSA's spectrophotometry tool is the independent reference to compare with.

Wavelength changes every exposure

SPHEREx's linear variable filters put a source at a new wavelength in each frame. A difference between two dates can be the spectrum, not a change in time. Compare within a channel.

No extinction in the 3D map

MG ignores interstellar dust. This is negligible within 100 pc but matters for the distant bright stars.

Background removal can remove real light

A constant or mesh background also removes nebulae or galaxies that fill the cutout. Use ZODI only, or no background, for diffuse emission.

Registration is checked, not forced

Frames are shifted to Gaia only with enough matched low-motion stars. The residual median, RMS and maximum are reported.
